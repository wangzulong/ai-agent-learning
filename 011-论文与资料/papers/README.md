## 精读卡统一格式

每张精读卡包含九节，顺序固定：

1. **元信息块**：标题 / arXiv 号 / 年份 / 作者机构
2. **一句话人话**：把摘要压缩成一句大白话
3. **生活类比**：不写代码也能懂
4. **核心贡献 3 点**
5. **关键实验数据**：具体数字，不确定的标注"需核对原文"
6. **对后续领域的影响**：谁站在它肩膀上
7. **与 001~010 的衔接**：映射到你的专题笔记
8. **可跳过部分提示**：省时间的砍法
9. **自测 2 题**：答得上来才算读过
