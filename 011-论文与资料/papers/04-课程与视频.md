# 04-课程与视频

> 论文教思想，课程教体系，视频教直觉。按"公开课 → YouTube → 中文资源"三层组织，全部标注免费/付费。
> 使用建议：同一时间只跟一门课 + 一个视频频道，贪多是学不完的头号原因。

## 一、公开课（有作业、有体系）

| 课程 | 机构 | 免费/付费 | 一句话 | 优先级 |
|---|---|---|---|---|
| AI Agents in LangGraph / Functions, Tools and Agents（短课系列） | DeepLearning.AI（Andrew Ng） | 免费 | 每个 1~2 小时的短平快工作坊，含 Jupyter 作业，周末就能过完 | ★★★ |
| Agentic AI（新短课系列） | DeepLearning.AI | 免费 | Andrew Ng 2025 年新做：反思/工具使用/规划/多 agent 四种设计模式的逐个实现 | ★★★ |
| Hugging Face Agents Course | Hugging Face | 免费 | 从零写 agent 到 MCP、再到多 agent，配套 HF 生态实操，证书免费领 | ★★★ |
| LLM Agents MOOC | UC Berkeley（RDI） | 免费 | 大学名系的全学期体系课：从 transformer 到 agent 评估，讲座全部公开录像 | ★★ |
| CS336: Language Modeling from Scratch | Stanford | 免费（公开录像+讲义） | 造一遍 LLM 才算真懂：分词→预训练→对齐全流程硬核课，想深挖底层再看 | ★★ |
| 深度学习专项课程（旧但仍是地基） | DeepLearning.AI / Coursera | 免费旁听，付费拿证书 | 已经有深度学习基础的可跳过 | ★ |

## 四、付费课（要不要花这个钱？）

| 课程 | 平台 | 价格量级 | 判断 |
|---|---|---|---|
| Maven 上的 Agent/Evals 实战小班（Hamel Husain & Charles Frye 等） | Maven | 数百美元 | 你已就业且有明确 eval 需求时值回票价；初学者先用免费资源 |
| Coursera/edX 付费证书 | Coursera | 订阅制 | 内容多为免费旁听可及，只为证书买单不必要 |
| 国内平台 Agent 实战课 | 各平台 | 数百元 | 谨慎：大概率是免费公开课内容的重组，买前先看免费目录 |

**结论**：本领域免费资源质量极高，付费课的唯一正当理由是"结构化 + 有人盯着"。上面的 ★★★ 免费组合走完，超过绝大多数付费课。
