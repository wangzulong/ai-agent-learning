# 08 - 自测篇：题库与面试题（主动回忆 + 间隔重复）

> **用法**：合上笔记作答，再核对；错题入错题本，按 D1/D3/D7/D21 重做。

---

## L1 概念题（01-02 篇）

1. 语言模型在建模什么？用一个公式 + 一句人话。
2. token 是什么？中文与英文的 token 换算比例？为什么"按字数估成本"必错？
3. embedding 把什么变成了什么？RAG 检索用的 embedding 和模型内部的 embedding 是一回事吗？
4. 注意力机制里 Q/K/V 各自的角色？n² 代价指什么？
5. decoder-only + 自回归是什么意思？流式输出为什么是"天然"的？
6. 上下文窗口的定义？"输入+输出共享窗口"是什么意思？
7. MoE 的总参/激活参分别决定什么？读一下 `Qwen3.6-35B-A3B` 这个名字。
8. KV cache 解决什么问题？它和 prompt caching 的区别？
9. temperature/top_p 各控制什么？temperature=0 保证什么不保证什么？
10. 思考 token 是什么、怎么计费？哪些模型有、旋钮叫什么？

## L2 原理与训练题（03-04 篇）

1. 画出六站前向流水线，标注 Transformer 块内的两个子层。
2. 位置编码（RoPE）解决什么问题？没有它模型会犯什么错？
3. Prefill 和 Decode 两阶段各自在干什么、瓶颈各是什么？TTFT 由哪个决定？
4. KV cache 为什么省算力？为什么瓶颈又转向显存带宽？
5. 缩放定律与 Chinchilla 修正各说了什么？第二缩放定律缩放的是什么？
6. RLHF 三步流程？DPO 省掉了什么？R1 式 RL 的"可验证奖励"为什么关键？
7. "涌现能力"争论双方论点？对你的选型行为有什么影响？
8. 蒸馏的原理？R1 蒸馏版对你本地部署的意义？

## L3 应用与生产题（05-06 篇）

1. 三家 SDK 的 system 写法差异？Anthropic 的两个"不要传"参数及原因？
2. 为以下任务配置模型档位+参数：① 邮件分类 ② 合同风险审查 ③ 海量历史单据归档 ④ Agent 主控。
3. 写出"约束解码 vs 提示词要 JSON+重试"的强度对比和各自适用条件。
4. 自部署决策清单四条，逐条判断你公司 CTRM 场景（数据敏感、日均 2 万次抽取）该不该本地化。
5. 手算成本：日均 1 万次、prompt 2k token（90% 缓存命中）、输出 500 token，Sonnet 5（$2/$10、缓存 0.1×）月成本？走 batch（5 折）呢？
6. Agent 多轮场景成本爆炸的机理与三个对策？
7. 模型退役迁移 checklist 七条，默写至少五条。
8. 降级链路：为"限流 / 上下文超限 / 结构化校验失败"各设计一条处理路径。

## L4 面试题（大厂 AI 应用岗风格）

1. 向完全不懂 AI 的 CTO 解释：为什么 LLM API 按 token 计费、为什么输出比输入贵 5 倍？（考原理变现）
2. 为什么 2026 年主流全是 MoE？稠密模型还有生存空间吗（举 Qwen3.6-27B 反例）？（考架构理解）
3. 长上下文窗口从 8K 涨到 1M，"lost in the middle"问题解决了吗？工程上怎么对抗？（考 context rot，联动 008）
4. 设计一个"成本可控的文档问答系统"：模型分级、缓存设计、批处理、监控指标全链路。（考 05+06 综合）
5. RLHF 和 R1 式 RL 的本质区别是什么？各自适合什么任务？（考训练范式）
6. 你如何评估"该用推理模型还是通用模型"？给出可量化的决策规则。（考成本质量权衡）
7. 为什么 Claude 4.6+ 禁用了手动采样参数？这反映了模型行业什么趋势？（自适应取代手动控制）
8. 国产模型 vs 闭源三强，从 token 效率、合规、价格、生态四个维度做结构化对比。（考格局认知）
