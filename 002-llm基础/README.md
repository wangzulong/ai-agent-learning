# 002 - LLM 基础 学习专题

> 这是 AI Agent 学习路线的地基层。**Agent 的一切行为都建立在 LLM 的机制之上**——不懂 token 和注意力，就永远只能"调 API 的 Черный 盒"；懂了底层，你才能读懂官方文档里的每个参数、诊断线上怪象、在模型格局剧变时不慌。

## 📚 本专题使用的学习方法（与 001/008 一致）

| 方法 | 在笔记中的体现 | 你该怎么做 |
|---|---|---|
| **费曼技巧** | 每个概念先用【一句话人话】+【生活类比】，再进技术细节 | 读完后把"Transformer 在干什么"讲给同事听，卡壳处回读 |
| **黄金圈法则** | 01 先讲"为什么工程师要懂底层"，再讲"是什么"，最后"怎么用" | 不要跳过 Why |
| **康奈尔笔记 + 主动回忆** | 每章开头【本节问题】，结尾【本节自测】 | 读前扫问题，读后**合上笔记**作答 |
| **间隔重复** | 08-自测篇提供 D1/D3/D7/D21 计划 | 按计划重做错题 |
