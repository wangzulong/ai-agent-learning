## 本专题的三个贯穿原则

1. **模型只生成调用意图**：它从不执行任何东西。所以权限校验、参数校验、业务校验全在你的代码里——把模型输出当**不可信的外部输入**对待（和对待前端请求体一样）。
2. **工具描述即接口文档即提示词**：模型选工具、填参数完全依赖 description。写 description 是在写"给模型读的 Swagger + 教程"，04 篇给出十条军规。
3. **错误信息是给模型读的信息**：好的错误消息能让模型自己改参数重试；差的错误消息会让它死循环或放弃。工具层的错误处理不是异常处理，是**上下文设计**。
