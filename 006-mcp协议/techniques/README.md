## 学习路线

```text
01 问题篇   —— 为什么需要（痛点：M×N 集成地狱）

03 原理篇   —— 怎么运转（一次调用的完整序列、握手与能力协商）
04 进阶篇   —— 怎么设计（三原语边界、传输选型、sampling）
05 实战篇   —— 怎么写（Python 手写 CTRM 库存 MCP Server 全代码）
06 生产篇   —— 怎么上生产（OAuth 2.1、攻击面、部署、审计）
07 对比篇   —— 怎么选型（vs Function Calling / A2A / OpenAPI）
08 自测篇   —— 怎么验证（题库 + 面试题）
```

## 自测速通（若 5 分钟能答对，可跳读部分章节）
