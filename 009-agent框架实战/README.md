# 009 · Agent 框架实战

> 主题定位：把手写 Agent 循环升级为**框架驱动**。以 LangGraph 重写 003 篇的点价 Agent 为主线，讲透框架的共性架构、持久化、Human-in-the-Loop、可观测与选型决策。
>
> 读者画像：中基集团 CTRM 贸易系统开发者（Java 11 + Vue 2.7 + MySQL）。实战代码以 Python 为主，每章附 Java 生态对照（Spring AI / LangChain4j），方便平移到现有技术栈。

## 与前面章节的衔接

| 前置章节 | 本文承接点 |
|---|---|
| 003 · Agent 从零实现 | 本文把 003 手写的"路由→抽取→查库存→查价→生成建议单→人工确认"循环，逐件映射到 LangGraph 的工程件上，实战篇给完整重写代码 |
| 004 · RAG | 04 篇的检索件在框架里通常作为一个节点接入，本文 06 篇讲评估时沿用 004 的检索评估思路 |

## 学习路线（建议顺序）

1. **建立问题意识**：00 背景篇 → 01 问题篇。搞清"框架到底省了什么、没省什么"。
2. **攒概念**：02 概念篇 12 张概念卡，配 009-03 概念地图反复看。
3. **看穿共性**：03 原理篇。所有框架都是"状态容器 + 调度循环 + 工具运行时 + 持久化钩子 + 可观测钩子"五件套。
4. **上手重写**：04 进阶篇（持久化与 HITL 原理）→ 05 实战篇（点价 Agent 全代码，边读边跑）。
5. **走向生产**：06 生产篇（trace / 评估 / 部署）。
6. **会选型**：07 对比篇决策树 + 六框架大表；08 自测篇检验。
7. **Java 团队**：每章末尾的 Spring AI / LangChain4j 对照段落不要跳过；07 对比篇有专门的 Java 选型结论。

- 每章开头【本节问题】给出 4 个驱动问题；结尾【本节自测】5~8 题。

- 时效性事实均标注来源与日期，检索不到的标注"截至 2026-09 未见权威披露"。
- 贯穿案例：**点价 Agent**（CTRM 场景：客户报盘 → 路由 → 抽取 → 查库存 → 查价 → 生成建议单 → 交易员人工确认）。
