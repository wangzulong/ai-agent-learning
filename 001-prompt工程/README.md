# 001 - Prompt工程 学习专题

> 这是 AI Agent 学习路线的第一站。提示工程（Prompt Engineering）是与 LLM 沟通的手艺——**模型再强，提示不对，输出就是开盲盒**。它是后面所有专题（Agent 架构、工具调用、RAG）的地基。

## 📚 本专题使用的学习方法（先读这段）

本专题笔记不是资料的堆砌，而是按**三种经过验证的学习方法**组织：

| 方法 | 在笔记中的体现 | 你该怎么做 |
|---|---|---|
| **费曼技巧**（Feynman Technique） | 每个概念先用【一句话人话】+【生活类比】讲解，再进入技术细节 | 读完后，尝试用自己的话把概念讲给同事听；讲不下去的地方就是你没懂的地方，回到笔记重读 |
| **黄金圈法则**（Why → What → How） | 章节顺序：先讲"为什么需要"（01），再讲"是什么"（02），最后讲"怎么写/怎么用"（03-06） | **不要跳过 Why 部分**——知道为什么，细节才挂得住 |
| **康奈尔笔记法 + 主动回忆**（Active Recall） | 每章开头有【本节问题】清单（带着问题读），结尾有【本节自测】（合上笔记作答） | 读前扫一眼问题；读后**合上笔记**做自测，答错的标记下来 |
| **间隔重复**（Spaced Repetition） | 08-自测篇 提供 D1/D3/D7/D21 复习计划 | 按计划重做错题，而不是一次性刷完 |

**给工程师的建议**：05-实战篇 不要只读，**一定要跑**。费曼技巧对代码同样适用：跑通后把示例删掉凭记忆重写一遍。

## 🆕 本笔记时效性说明（2026-09 更新）

提示工程领域变化极快，本笔记已纳入截至 2026 年 9 月的最新事实：

- **OpenAI GPT-5 官方提示指南**：agentic eagerness 控制、`reasoning_effort`/`verbosity` 参数、Responses API 保留推理上下文
- **Anthropic 最新最佳实践**：XML 标签与角色提示的推荐已**大幅放宽**（现代模型不再强制需要）
- **Claude prefill 已废弃**（Sonnet 4.5 起 400 报错），改用结构化输出
- **推理模型 vs 通用模型**的提示策略分野（o 系/R1/GPT-5 类 vs 传统 instruct 模型）
- **Context Engineering 接棒 Prompt Engineering** 的行业趋势（Anthropic 2025-09 官方文章）
- **The Prompt Report**（arXiv:2406.06608）58 种技术的权威分类体系
