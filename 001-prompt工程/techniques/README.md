## 本专题的三个贯穿原则

1. **提示词是代码**：要版本管理、要测试、要评审——不是聊天记录。
2. **技巧有半衰期，原理不过期**：记不清技巧时，回到 03-原理篇用第一性原理推导。
3. **先测量再优化**：没有 eval 的提示词优化 = 闭眼调参（06-生产篇）。
