## 一、这套系列在讲什么（一段话版本）

AI 把"写代码"加速到了人无法审查的速度，软件危机以新形态回归——**这次要驯服的不是人的代码，而是 AI 的代码**。作者提出 AI Harness（"挽具"）工程方法论：人不再靠"看得够快"守质量（review 追不上生成速度），而是**靠事先圈好边界**——用一套"规约文件体系"（约束金字塔）+ 自动门禁 + 记忆/归因/测试自成长机制，给 AI 装上"约束、记忆、归因、免疫、自知"五件器官。核心命题一句话：**当代码由 AI 生成，人不再通过"写代码"控制质量，而是通过"构建约束体系"引导 AI 的行为空间。管得住的快，才是真的快。**

| 02 | 战略层·宪章（09-04） | 宪章回答三问：我们是谁 / 边界在哪 / 怎么共事；是所有参与者开工前强制加载的"行为契约" | **编码十诫**（先读再写、不信回忆、涟漪必检、手术刀式改动…）；**反谄媚条款** + 置信度标注 [HIGH]/[MED]/[GUESS]；优先级铁律：宪章 > AGENTS.md > skill |
| 03 | 架构层·ADR（09-05） | 离开对话线程的决定等于没做决定；"为什么"必须落成单一事实来源 | ADR 模板：状态/决策者/背景/决策/理由/后果/应对；Swarm-Fed ADR（多 Agent 共识反喂决策库）；TradeOMS 20 条、SmartQuant 11 条 |
| 04 | 契约层（09-06） | AI"从不认为自己在猜，它认为自己在执行"——必须把"怎么做"从对话搬进契约 | Spec 三栏（范围/假设/验收标准）；数据契约 = Level 1 硬边界，路由门禁扫出 233→370→0 条不匹配；FMEA（RPN>100 必须对策，KYC 越权 392）；三轨制三权分立（报告人≠修复人≠验证人） |
| 05 | 门禁层（09-07） | 约束是文本，门禁是执行；没有门禁，上面四层全是纸。旧语法门禁拦不住 AI 的语义错误 | 数据：AI 代码 ~1/5 含虚假库引用（CodeRabbit 470 仓库）、语法通过 92% 但逻辑仅 78%（Google 盲评）、AI bug 率是人的 1.7 倍；G0-G6 六阶段门禁 + 三原则（能量化/在发布前/失败有返回路径）；第一天可上：断言有效性、引用溯源、涟漪扫描 |
| 06 | 实现层·幂等与退化（09-08） | AI 会挂且挂得干脆；底线不是"引擎不会坏"，是"坏了业务不停" | 幂等键（种子脚本 ON DUPLICATE KEY UPDATE）；退化必须**可见**（汇率缓存+降级提示）；**系统可以被杀死，但不能被静默**（全员暴毙事故：后台进程禁用 set -e + 看门狗 5 分钟巡检）；恢复瓶颈在"找"不在"修"（pre-compile-check.sh：45min→5min） |
| 07 | 执行前宣言（09-10） | 磨刀永远在砍柴之前：规定**文件创建顺序**，让约束文件先于代码存在 | 四阶段：Manifest 六问（WHAT/WHY/APPROACH/FILES/SUCCESS/STOP，改动 >3 文件或 >30 分钟必写）→ Spec+ADR → Gate 先立门禁再放 AI → Manual+Runbook 边做边沉淀；案例：省 3 分钟 Manifest 赔一下午（给被限流接口加缓存） |
| 08 | 多 Agent 编排（09-10） | 蜂群无中心调度也能协作；单模型独断关键任务链是设计错误 | 工作窃取（Work Stealing）取代静态分配；看门狗：失效→恢复 <5 分钟；串行 45 分钟 → 7 通道并行几分钟；**62% 欺诈率耳光**：涉钱动作必须多模型独立投票；"一群高效讨论的 Agent = 昂贵的聊天室" |
| 09 | 记忆与知识（09-11） | AI 每次会话都是一场失忆；**失忆的聪明，不如记得住的平庸**；知识库好坏看"检索方式"不看"内容多少" | "富内斯崩溃"（过目不忘反而无能）；derekinside：14 wings/45 房间/555 页/2651 知识块，AGENTS.md 强制"先查再思考"，检索 <1s（gbrain 5-10s→<1s 是激活关键）；给记忆配清洗（过期降级） |
| 10 | 调试与归因·冰山（09-12） | "这是哪里错了"是陷阱问题；水面下分三层：现象 L1 / 结构 L2 / 设计 L3 | 硬规矩：**禁止把"数据问题"当根因**；三层分析完才许修；涟漪分析 R0-R4 四级级联回归（动契约=全量回归）；三轮才到根因的超时 bug；矫枉不过正："停在这层会不会卷土重来？" |
| 11 | 测试与自成长（09-14） | 从失败里积累知识（波普尔）；测试是把失败当原料、让它自己越长越厚的体系 | fulltest：10 秒全量回测；失败模式账本（认识的失败→按方修，**不认识的失败才是金子**）；喂食闭环（未知失败日志+三层数 Issue+fix 提交）；**基线自己爬**：每次变好固化成回不去的底线；FMEA 兜测不到的地方 |
| 12 | 成熟度模型（09-15） | 体系强弱不看多能答对，看能不能认出自己答错（达克效应）；**成熟不在能力，在确定性；确定性之上是自知** | G0 不知道自己不知道 → G6 自诊断演进；G 级是海图不是打怪升级表；四个项目站在不同切面；反过度工程：知道站哪级，才清楚下一步补什么 |

## 五、全系列高频金句摘录

1. 管得住的快，才是真的快。
2. 当你不能靠"看得够快"守住质量，就必须靠"事先圈好边界"守住质量。
3. 离开对话线程的决定，等于没做决定。
4. AI 从不认为自己在猜，它认为自己在执行。
5. 质量不是检查出来的，但没有检查的质量，是声称出来的。
6. 系统可以被杀死，但不能被静默。
7. 问题不是不存在，是以前没人知道它存在（233→370→0）。
8. 未知的未知，第一次变成已知的已知。
9. 让 AI 不用猜，而不用猜的 AI，才是可靠的 AI。
10. 当你发现一群 Agent 在"高效地讨论"，你是在用一个昂贵的聊天室。
11. 失忆的聪明，不如记得住的平庸；五秒是一道心理门槛，十秒是一道天堑。
12. 停在表面的诊断只是止痛，钻到根因的修复才是根治。
13. 基线的意义：把每一次变好，固化成回不去的底线。
14. 成熟不在能力，在确定性；确定性之上，还有一层更狠的，是自知。
