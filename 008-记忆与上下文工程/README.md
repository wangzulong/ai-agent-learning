# 008 - 记忆与上下文工程 学习专题

> 这是 AI Agent 学习路线中的记忆模块。记忆（Memory）与上下文工程（Context Engineering）是 Agent 与普通 Chatbot 的分水岭——**没有记忆的 Agent 每次醒来都是失忆状态**。

## 📚 本专题使用的学习方法（先读这段）

本专题笔记不是资料的堆砌，而是按**三种经过验证的学习方法**组织：

| 方法 | 在笔记中的体现 | 你该怎么做 |
|---|---|---|
| **费曼技巧**（Feynman Technique） | 每个概念先用【一句话人话】+【生活类比】讲解，再进入技术细节 | 读完后，尝试用自己的话把概念讲给同事听；讲不下去的地方就是你没懂的地方，回到笔记重读 |
| **黄金圈法则**（Why → What → How） | 章节顺序：先讲"为什么需要"（01），再讲"是什么"（02），最后讲"怎么实现/怎么用"（03-06） | **不要跳过 Why 部分**——知道为什么，细节才挂得住 |
| **康奈尔笔记法 + 主动回忆**（Active Recall） | 每章开头有【本节问题】清单（带着问题读），结尾有【本节自测】（合上笔记作答） | 读前扫一眼问题；读后**合上笔记**做自测，答错的标记下来 |
| **间隔重复**（Spaced Repetition） | 08-自测篇 提供 D1/D3/D7/D21 复习计划 | 按计划重做错题，而不是一次性刷完 |

**给工程师的建议**：代码章节（05-08）不要只读，**一定要跑**。费曼技巧对代码同样适用：跑通后把示例删掉凭记忆重写一遍。
