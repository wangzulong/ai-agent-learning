## 1. 环境准备

```bash
# Python 3.10+，安装 SDK
pip install mem0ai

# 用 Qdrant 时需要客户端 + 启动服务（Chroma 则零部署）
pip install qdrant-client
docker run -p 6333:6333 qdrant/qdrant

# 默认走 OpenAI，先配 Key
export OPENAI_API_KEY="sk-..."
```

## 2. 最小示例（默认配置，5 分钟）

```python
from mem0 import Memory

m = Memory()

# 1) 存：传入对话消息 + 用户标识
messages = [
    {"role": "user", "content": "Hi, I'm Alex. I love basketball and gaming."},
    {"role": "assistant", "content": "Hey Alex! I'll remember your interests."},
]
m.add(messages, user_id="alex")

# 2) 查：带作用域过滤
results = m.search("What do you know about me?", filters={"user_id": "alex"})
print(results)
```

返回结构（对照 02-概念篇卡片 7）：

```json
{
  "results": [
    {
      "id": "mem_123abc",
      "memory": "Name is Alex. Enjoys basketball and gaming.",
      "user_id": "alex",
      "categories": ["personal_info"],
      "created_at": "2025-10-22T04:40:22.864647-07:00",
      "score": 0.89
    }
  ]
}
```

**默认装配清单**（排错时心里要有这张表）：

| 组件 | 默认值 |
|---|---|
| LLM | OpenAI `gpt-5-mini`（提取 + 更新决策） |
| Embeddings | OpenAI `text-embedding-3-small`（1536 维） |
| 向量库 | 本地 Qdrant，数据落盘 `/tmp/qdrant` |
| 历史库 | SQLite `~/.mem0/history.db` |
| Reranker | 未启用 |

## 3. Platform 版（托管，零基础设施）

```python
import os
from mem0 import MemoryClient

client = MemoryClient(api_key=os.getenv("MEM0_API_KEY"))  # app.mem0.ai 获取

client.add(messages, user_id="user123")
results = client.search(
    "What are my dietary restrictions?",
    filters={"user_id": "alice"},
)
```

区别：向量库/reranker 全托管、Graph Memory 自动开启、有审计日志与 workspace 治理；高级功能（webhooks、多模态、自定义分类）即开即用。

## 4. CRUD 全 API 实操

```python
from mem0 import Memory
m = Memory()

# ---- 存 ----
m.add(
    [{"role": "user", "content": "我在做 CTRM 系统，偏好用 Vue 2.7"}],
    user_id="dev001",
    metadata={"team": "trading"},            # 自定义过滤标签
    infer=True,                              # 默认：LLM 提取事实
)
m.add(
    [{"role": "user", "content": "合同额度表结构：info_customer_contract_limit..."}],
    user_id="dev001",
    infer=False,                             # 存原文，适合表结构/条款类内容
)

# ---- 查 ----
m.search("他偏好什么前端框架？", filters={"user_id": "dev001"})   # 语义检索
m.get_all(filters={"user_id": "dev001"})                          # 列出全部

# ---- 改 / 删 ----
r = m.search("Vue", filters={"user_id": "dev001"})
mid = r["results"][0]["id"]
m.update(mid, "偏好 Vue 2.7，正计划迁移 Vue 3")                    # 显式修正
m.delete(mid)                                                     # 删单条
# m.delete_all(filters={"user_id": "dev001"})                     # 清空某作用域

# ---- 审计 ----
m.history(memory_id=mid)      # 看这条记忆的 ADD/UPDATE/DELETE 全过程
```

## 5. 自定义配置（换模型 / 换向量库 / 加 reranker）

```python
from mem0 import Memory

config = {
    "vector_store": {
        "provider": "qdrant",
        "config": {"host": "localhost", "port": 6333},
    },
    "llm": {
        "provider": "openai",
        "config": {"model": "gpt-5-mini", "temperature": 0.1},   # 提取温度 ≤ 0.2
    },
    "embedder": {
        "provider": "openai",
        "config": {"model": "text-embedding-3-small"},
    },
    "reranker": {
        "provider": "cohere",
        "config": {"model": "rerank-v3.5"},   # 需 COHERE_API_KEY；top_k 建议 10~20
    },
}
memory = Memory.from_config(config)
```

也支持 YAML：`config = yaml.safe_load(open("config.yaml"))` 后传入 `from_config`。

### Provider 速查表（Python）

| 组件 | 可选 provider |
|---|---|
| LLM | openai, anthropic, gemini, groq, **ollama**, aws_bedrock, azure_openai, **litellm** |
| Embedder | openai, gemini, azure_openai, **ollama**, huggingface, vertexai, aws_bedrock |
| 向量库 | **qdrant**, **pgvector**, **chroma**, pinecone, redis, weaviate, milvus, elasticsearch |

> 💡 国内项目常见组合：LLM 用 `litellm`（转发 DeepSeek/Qwen/GLM）或 `ollama`（本地），向量库用 `chroma`（零部署）或 `pgvector`（复用现有 PostgreSQL）。

## 6. 本地化方案（Ollama + Chroma，断网可跑）

```bash
ollama pull llama3.1          # 或 qwen2.5 等中文友好模型
pip install chromadb
```

```python
config = {
    "llm": {
        "provider": "ollama",
        "config": {
            "model": "llama3.1",
            "temperature": 0.1,
            "ollama_base_url": "http://localhost:11434",
        },
    },
    "embedder": {
        "provider": "ollama",
        "config": {"model": "nomic-embed-text"},
    },
    "vector_store": {
        "provider": "chroma",
        "config": {"collection_name": "agent_memory"},
    },
}
memory = Memory.from_config(config)
```

**本地化的代价**：小模型的提取/更新决策质量明显低于 GPT 级模型，事实漏提、误判增多——生产要权衡，或"提取用强模型、检索用本地"混合。

### 本地模型怎么选（社区实践建议）

- **抽取 LLM**：抽取是结构化任务，**1B~12B 小模型即可胜任**（别低于 1B，除非微调过）；Hugging Face 按 Text Generation 筛选。推荐 **Qwen3 8B** 一档（中文友好；mem0 云端常见搭配是 GPT-5 Mini 量级）
- **Embedding**（Feature Extraction 类）候选（四条互为备选，不是流水线）：

| 模型 | 特点 |
|---|---|
| BAAI/bge-m3 | 多语 · dense + sparse（中文项目首选） |
| intfloat/e5-large-v2 | 英语检索强 |
| nomic-ai/nomic-embed-text-v1.5 | 长上下文 embedding |
| gte-Qwen2-1.5B-instruct | instruction-aware 检索 |

- 选型看**对应领域/语言的 embedding 榜单**（多语、英语、医疗等各有榜单）
- **长期路线**：微调自己的小模型，本地效果更稳

> 来源补充：[Agent 长期记忆（以 Mem0 为例）](https://github.com/juliepy/AI-Engineer-from-scrach/blob/main/99-My%20idea/AI%20Agent%20%E5%AD%A6%E4%B9%A0%E6%8C%87%E5%8D%97/01.longterm%20memory.md)——含源码级细节与本地选型的社区文章，具体数值随 SDK 版本可能变化。

## 7. Node.js 版要点

```javascript
import { Memory } from "mem0ai/oss";   // ⚠️ OSS 必须从这个入口导入

const memory = new Memory({
  version: "v1.1",
  embedder: { provider: "openai", config: { model: "text-embedding-3-small" } },
  // TypeScript 配置键为 camelCase
});
```

- provider SDK 是**可选 peer 依赖**：用 Qdrant 要 `npm install @qdrant/js-client-rest`，只装 `mem0ai` 不带它们
- 报 `Cannot find module` 九成是入口写错或缺 provider 依赖

## 8. 排错速查表

| 现象 | 原因 | 解决 |
|---|---|---|
| Qdrant 连接失败 | 6333 未暴露 / key 不匹配 | 查 docker 映射与鉴权配置 |
| 搜索恒为空 / 维度报错 | embedder 模型或维度不一致 | 全链路统一 embedder（如 1536 维） |
| `Unknown reranker` | SDK 太旧 | `pip install --upgrade mem0ai` |
| 提取出的事实质量差 | 提取温度过高 / 模型太弱 | 温度 ≤ 0.2；换强模型；或自定义提取 prompt |
| 记忆互相串 | 检索漏了 filters | 所有 search/get_all 强制带作用域 |
| 想存原文却存了摘要 | infer 默认开启 | `infer=False` |

## 9. 动手练习（建议按序完成）

1. **最小验证**：默认配置 add → search，观察提取出的事实与 score
2. **作用域实验**：同一 `user_id` + 两个不同 `agent_id` 读写，验证隔离与共享
3. **冲突实验**：先存"我不吃辣"，再对话"最近开始吃辣了"，观察 DELETE/UPDATE 决策与 `history()`
4. **本地化实验**：Ollama + Chroma 断网跑通，对比提取质量差异
5. **infer 对照**：同一段话分别 `infer=True/False` 入库，比较检索表现
