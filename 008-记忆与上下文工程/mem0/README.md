## 一句话费曼解释

**mem0 就是给 AI Agent 配的一个"外挂档案室 + 档案管理员"**：你把对话丢给它，管理员自动把值得记的事写成档案卡片存好（去重、归档、更新）；下次要用时，你说一句查询，它把最相关的几张卡片递给你，塞进 prompt。效果：Agent 像认识你一样接话，而 token 花费只有"回放全部聊天记录"的零头。

## 概念地图（全局鸟瞰）

```
                        ┌──────────────────────────────┐
                        │        你的应用 / Agent        │
                        └──────┬───────────────┬───────┘
                        add()  │               │ search()
                               ▼               ▼
              ┌────────────────────────────────────────────┐
              │                 mem0 记忆层                  │
              │                                            │
   写入路径    │   提取阶段            更新阶段               │    读取路径
  ┌─────────┐ │  ┌──────────┐   ADD   ┌──────────┐          │  ┌──────────┐
  │ 对话消息 │─┼─▶│ 上下文查找 │──候选──▶│ LLM工具调用│          │  │ 四路信号   │
  └─────────┘ │  │ 事实提取  │   事实   │ UPDATE   │          │  │ 语义/关键词│
              │  │ 去重+向量化│───┐     │ DELETE   │          │  │ 实体/时间  │
              │  │ 实体提取  │   │     │ NOOP     │          │  └────┬─────┘
              │  └──────────┘   │     └────┬─────┘          │       │
              │                 ▼          ▼                │       ▼
              │        ┌─────────────────────────┐          │  ┌──────────┐
              │        │ SQL库(事实) + 向量库(嵌入) │          │  │ 相关记忆  │
              │        │ + 实体存储(实体/图连接)    │          │  │ → 注入prompt│
              │        └─────────────────────────┘          │  └──────────┘
              └────────────────────────────────────────────┘

   作用域隔离： user_id(用户长期) │ agent_id(某Agent) │ run_id(单次任务) │ metadata(自定义)
```

## 速查：最常用 API（详细见 05）

```python
from mem0 import Memory
m = Memory()
m.add(messages, user_id="alex")                                   # 存
m.search("query", filters={"user_id": "alex"})                    # 查
m.get_all(filters={"user_id": "alex"})                            # 列
m.update(memory_id, "新内容")                                      # 改
m.delete(memory_id)                                               # 删
m.history(memory_id)                                              # 审计变更
```
