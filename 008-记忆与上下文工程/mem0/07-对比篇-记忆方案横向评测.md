## 2. 主要方案逐一画像

### 2.1 mem0（本专题主角）
- **思路**：独立记忆层——LLM 提取事实 → 两阶段管线维护 → 向量（+实体加成）混合检索
- **强项**：工程化最好（API 简洁、文档全、OSS+托管双形态）、延迟与 token 开销最低档、LoCoMo 综合表现强、生态接入广（LangChain/CrewAI/MCP…）
- **短板**：带类型的关系推理弱（现役 Graph Memory 是共现图）；OSS 无图记忆
- **适合**：绝大多数需要用户/会话记忆的产品（客服、助理、教育、CRM）

### 2.2 Zep / Graphiti
- **思路**：**时序知识图谱**——把对话沉淀成带时间边的图，答案要"时间一致"（现在是/曾经是）
- **强项**：开放域与时序问题表现顶尖（LoCoMo 开放域 J=76.60）；关系推理深
- **短板**：**token 开销巨大**（论文实测 >600k/对话，是原始对话的 20 倍）、记忆可用延迟高（数小时 vs mem0 一分钟内）
- **适合**：知识关系复杂、时间演变重要的场景（企业知识管理、复杂用户关系网络）

### 2.3 Letta（MemGPT 商业化）
- **思路**：**LLM 即操作系统**——把上下文窗口当内存，记忆分页换入换出，Agent 自己调工具管理记忆
- **强项**：超长会话优雅；记忆管理自主性强；Agent 状态持久化完整
- **短板**：每一步都为"记忆管理"消耗推理 token；学习曲线与运维复杂度高
- **适合**：长周期、自主性强的 Agent（长期研究助理、持续运行的数字员工）

### 2.4 LangMem（LangChain 生态）
- **思路**：LangChain 官方记忆库，与 LangGraph 状态机天然融合
- **强项**：LangChain 用户零摩擦；热/温/冷记忆分层理念清晰
- **短板**：LoCoMo 表现一般（J=58.10）；强绑定 LangChain 生态
- **适合**：已 All-in LangChain 的团队

### 2.5 HippoRAG（研究向）
- **思路**：模仿海马体记忆索引——PPR（个性化 PageRank）+ 知识图谱做检索
- **强项**：多跳问题学术表现好；开源可复现
- **短板**：偏研究组件，非生产记忆层；无更新/冲突处理等运维能力
- **适合**：论文复现、RAG 增强实验

### 2.6 OpenAI 原生 Memory
- **思路**：平台内置，ChatGPT 自动记住偏好
- **强项**：零成本开箱即用
- **短板**：黑盒、不可控、不可移植、LoCoMo 上 J=52.90 垫底梯队
- **适合**：个人玩具项目；**企业产品基本出局**（数据与行为都不可控）

## 4. 选型决策树（照着走）

```
你的 Agent 需要跨会话记忆吗？
├─ 否 → 不需要记忆层（别过度设计），用会话历史即可
└─ 是 → 数据能出你的服务器/用 SaaS 吗？
         ├─ 能 → 预算允许上托管吗？
         │        ├─ 是 → Mem0 Platform（均衡首选）
         │        │        └─ 特殊：关系推理极重 → Zep Cloud
         │        └─ 否 → Mem0 OSS（默认配置起步）
         └─ 否（必须私有化）
                  ├─ 需要时序/关系图谱推理吗？
                  │        ├─ 是 → Zep Graphiti（开源自部署）
                  │        └─ 否 → Mem0 OSS + Qdrant/pgvector
                  ├─ 已 All-in LangChain？→ 先试 LangMem
                  └─ 超长会话、Agent 全自主？→ 评估 Letta
```

**默认推荐**（80% 场景）：**Mem0 OSS 起步验证 → 量产后视情况切 Mem0 Platform**。理由：工程化最成熟、开销最低、双形态迁移平滑（API 兼容）。

## 5. 混用策略（进阶）

真实系统常常不止一个方案：

- **mem0（用户记忆）+ 传统 RAG（知识库）**：最常见组合，见 06-生产篇 §4
- **mem0（事实记忆）+ Letta/自研（工作状态）**：分层各司其职
- **mem0 Platform + 自建向量库（私有语料）**：敏感语料不出域，用户记忆走托管

## 6. 值得跟踪的方向（2026 视角）

- **多模态记忆**：图像/音频交互的沉淀（论文自认的空白）
- **记忆治理**：合规审计、租户级保留策略、遗忘权自动化
- **压缩引擎**：更激进的记忆蒸馏，进一步压 token
- **评测标准化**：LoCoMo / LongMemEval / BEAM 之外更贴近真实业务的基准
